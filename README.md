# HerHealth-AI

## Project Overview

HerHealth-AI is an AI/ML-based women's health project designed to provide basic health-risk prediction and awareness.

The project currently includes machine-learning modules related to:

- PCOS Prediction
- Ovulation Prediction
- Period-related analysis

> **Note:** This project is developed for educational and awareness purposes only. It should not be used as a medical diagnosis system.

## Features

- PCOS prediction using Machine Learning
- Ovulation prediction using a trained ML model
- Missing-value handling using an imputer
- Feature scaling using a saved scaler
- Saved ML models in `.pkl` format
- Python application for user interaction
- Jupyter notebooks for model development and testing
